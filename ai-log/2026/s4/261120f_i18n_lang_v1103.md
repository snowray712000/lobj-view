# 1.10.3: multilingual UI (zh default + English), `lang` button

Date: 2026-11-20. Project: `lobj-view`. Version 1.10.2 → 1.10.3.

## Context / User request
Make the UI multilingual. The switch button is always labelled `lang` (so it is findable whatever the current language). Add English now; default is Chinese; Vietnamese may come later.

## Decisions & rationale
- Frontend-only, no library: `web/src/i18n.ts` holds `zh` (base dictionary) and `en: Dict` (`Dict = typeof zh`), so a missing key in a new language is a compile error. Parameterised strings are functions in the dictionary (`t().convDone(path, deleted)`), letting English handle word order / plurals.
- Static HTML tagged with `data-i18n` (textContent), `data-i18n-title`, `data-i18n-placeholder`; bare text next to checkboxes/selects was wrapped in `<span data-i18n>` so the input is not wiped. `applyStatic()` also sets `<html lang>`.
- Live switch (no reload, models stay loaded): `setLang` → `applyStatic` → `onLangChange` listeners in main.ts re-render backend label, health error, jaw-regex tooltip, object panel (cards rebuilt; props live in `propsOf`), jaw badges, server stats (`lastStats`), busy tip, update badge (`lastUpdate`), open update/assoc dialogs (`lastAssoc`). One-off messages already shown (infoEl, convert results) stay in the old language.
- `Loaded.info` became `{verts, tris, counts}` so the card info string is composed at render time in the current language.
- `lang` button opens a small menu listing languages by their own names (中文 / English) with ✓; menu is `position: fixed` placed from the button rect because `#hud .box` has `overflow: hidden`.
- Saved in `localStorage['lobj-view-lang']`; default `zh`.
- English "original colour" swatch uses `∅` (one glyph fits the swatch; "orig" overflowed).

## Not translated (known limits)
Versions.md (version history dialog) and backend (Rust) error / `reason` / `notes` strings remain Chinese.

## How to add a language (e.g. Vietnamese)
Add `const vi: Dict = {...}` in `i18n.ts`, extend `type Lang`, `DICTS`, and `LANGS` (`{ code: 'vi', name: 'Tiếng Việt', html: 'vi' }`).

`web/src/i18n.ts` (new), `web/src/main.ts`, `web/index.html`, `web/src/style.css` (`#lang-btn`, `#lang-menu`), `Cargo.toml`/`Cargo.lock`, `README.md`, `doc/Versions.md`, rebuilt `web/dist`.
