# 1.17.2: `/stat` dataset statistics page + stat.csv

Date: 2026-11-26. Project: `lobj-view`. Version 1.17.2. Follows [261126j](261126j_to_lobj2_recursive_v1165.md).

## User request
Separate stats UI at `/stat`; per dataset, per case (= subfolder): upper/lower present and which FDI; output `stat.csv` (UTF-8) beside README.md. Columns: dataset_name | case name | upper | lower | all FDI (0/1) | remark. First test: `/home/shared/訓練原始資料/ACom_230914_121`.

## Decisions & rationale
- FDI read from `.lobj2` labels via `lobj::load` (always FDI); union across a case's files (`x_lower`, `x_lower_study`).
- Columns: 32 permanent + 20 primary FDI ("all FDI"). Jaw from labels; filename conflicts / read errors / study-vs-original FDI differences go to remark.
- dataset_name defaults to folder name minus `ACom_` (user example `230914_121`), editable on the page. case name = real folder name (`sets141_001`).
- UTF-8 with BOM so Excel does not mangle non-ASCII case names.
- Third Vite entry (`stat.html`, `src/stat.ts`); backend `src/dataset_stat.rs`; CSV built client-side, written by `POST /api/stat-save` (local-only).

## Verification
API run against the real dataset: 121 cases, 115 upper, 116 lower, 0 remarks. Save tested only on a temp dir. Browser UI NOT clicked through; real `stat.csv` not yet written into the dataset folder.
